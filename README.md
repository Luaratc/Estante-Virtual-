# Estante Virtual
## Sobre o projeto
Este projeto consiste em uma aplicação web para pesquisar, organizar e acompanhar livros de uma biblioteca pessoal.
A aplicação permitirá buscar livros por título ou autor utilizando a Google Books API e adicionar os resultados a uma estante virtual, facilitando a organização das leituras.

## Funcionalidades previstas
- Pesquisar livros pelo título ou autor.
- Visualizar informações dos livros encontrados, como capa, título e autor.
- Adicionar livros à biblioteca pessoal.
- Organizar os livros nas categorias "Quero Ler", "Lendo" e "Lidos".
- Alterar o status de leitura dos livros.
- Registrar avaliações e anotações pessoais.
- Editar informações e excluir livros da biblioteca.
- Salvar os dados no navegador utilizando localStorage.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Google Books API
- localStorage

## Objetivo
Projeto pessoal desenvolvido para praticar e aprimorar conhecimentos em desenvolvimento Front-end, integração com APIs e manipulação de dados utilizando JavaScript.
